DSLP2 makes the server broadcast its presence on LAN, so you can find it easier. It is a fork of [DSLP](https://modrinth.com/mod/dslp) by [0x000006](https://modrinth.com/user/0x000006).

It is **server-side only**, clients do not need this mod installed.
